The "memory" (i.e., importance) of older data in this filter fades at a rate dictated by the filter. In this case, the 50^th value is 50 times more important than the first, and the 100^th value is twice as important as the 50^th and 100 times more important than the first.

The exponentially-weighted filter provides the analyst with more flexibility. This filter uses F^i as a weighting factor, where the filter-control constant F is a value chosen between zero and one, and i is the "age-count" of the i^th data point. For this filter, i = 0 now designates the current or latest data point, i = 1 designates the immediately preceding or next-to-last data point, etc., so the data points are indexed in reverse chronological order starting with zero. The weighted least-squares solution is

X_n = (Σ_{i=0}^{n-1} F^i * x_{n-i}) / (Σ_{i=0}^{n-1} F^i) (18)

Using F = 0.9 and the same example as before,

X_3 = (F^0 * x_3 + F^1 * x_2 + F^2 * x_1) / (F^0 + F^1 + F^2)
= ((.9)^0(7) + (.9)^1(5) + (.9)^2(6)) / ((.9)^0 + (.9)^1 + (.9)^2)
= (7 + 4.5 + 4.86) / 2.71 = 16.36 / 2.71 = 6.04 (19)
